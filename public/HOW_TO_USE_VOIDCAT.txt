VOIDCAT HARNESS — COMPLETE OPERATOR GUIDE
=========================================

VoidCat Harness is a local-first desktop intelligence workspace. Chats, memories,
documents, embeddings, projects, and investigation records stay on this computer.
Only a source you explicitly enable, a web request you approve, or a model download
contacts an outside service.

QUICK START
-----------
1. Open VoidCat Harness from its desktop launcher.
2. Open UNIT BANK and select a local GGUF UNIT. The app discovers compatible files
   from the folders configured under UNIT SETTINGS.
3. Press LOAD UNIT. Wait for CORE ONLINE in the header.
4. Open COMMAND, type a message, and press Send.
5. When finished, close the app normally. VoidCat ejects the active UNIT on exit.

Example: Load a small instruction-tuned UNIT, open COMMAND, and ask:
"Summarize the active project and list any unresolved leads."

HEADER AND NAVIGATION
---------------------
The header shows the active project, number of discovered UNITs, core state, and
network policy. HOW_TO_USE_VC opens this guide. FX cycles interface motion through
OFF, LOW, MEDIUM, and HIGH; MEDIUM is the standard animated presentation. The
numbered left rail switches workspaces; it intentionally has no vertical scrollbar.

01 — HUNTER-SEEKER
------------------
Hunter-Seeker is a live geospatial board. REFRESH NOW deliberately refreshes enabled
sources within hard provider ceilings. Each source row can be enabled or disabled,
given a pull cadence, and assigned a lower request budget. A disabled source restores
its most recent in-memory snapshot when re-enabled before the next scheduled pull.

Map controls:
  • Click a marker to open details and provenance.
  • Right-click a contact, event, object, or region to investigate it in OSINT.
  • GLOBAL VIEW resets the map.
  • DeFlock loads a lightweight worldwide region index. Click a region hub to
    display only that sector's cameras. The index and selected sector remain in
    volatile memory for 24 hours, and revisiting the sector makes no new request.
  - YouTube Live Cameras uses the same bounded region-hub workflow. Enabling it for
    the first time opens the official Google Cloud setup for YouTube Data API v3.
    Click a CAM region hub to search that sector, then click a camera icon to replace
    the map with YouTube's continuous live-video player. Still-frame, ended, private,
    and non-embeddable results are excluded. Use the X in the player header to return
    to the map. Results are cached for 15 minutes to protect API quota.
  - Windy Public Webcams remains a separate layer with its own API key and offset
    WINDY region hubs. It includes Windy's public webcam catalog and visibly labels
    whether each provider player is live or a day/month/year timelapse. Windy and
    YouTube can be enabled independently or together.

Freshness states:
  LIVE      A recent successful observation.
  CACHED    Restored without a new provider request.
  STALE     Older than the source freshness window.
  DEGRADED  The provider or record is incomplete/unhealthy.

Optional sources are off by default. Enable only the layers needed for the current
task. NASA EONET category layers share one bounded response cache. CelesTrak orbital
groups enforce a two-hour provider floor and recalculate positions locally between
downloads. AISStream requires an API key and selected region. The credential dialog
tests and saves it through Electron's protected process.

Live Source Matrix:
  - The matrix contains all 41 integrated catalog sources plus the original VoidCat
    feeds that are not duplicates. Sources are organized into collapsible Weather,
    Natural Hazards, Conflict, Humanitarian, Environmental, Aviation, Maritime,
    Cameras, Transportation, Infrastructure, Cyber/Network, Space, News, and
    Government Records categories.
  - Checking an ordinary scheduled feed activates its existing live adapter.
  - Checking a bounded-query feed opens the required map scope, point, time window,
    dataset/resource, search, or protected-credential form. It is not shown as ON
    until the bounded request succeeds.
  - Positioned observations appear on the common map. Reference/catalog results open
    in an evidence list with provider links, publication time, license, cache state,
    and coverage limitations.
  - The eye changes map visibility without generating traffic. Opacity also applies
    to raster overlays. Turning a loaded query source off and back on restores its
    bounded in-memory result.
  - Automatic query refresh is optional. It processes one due source at a time,
    honors the selected local traffic budget, and never exceeds provider safeguards.

Expansion Source Catalog:
  - Open EXPANSION SOURCE CATALOG below the managed-job area.
  - LOAD VIEW queries a bounded map viewport/point. SEARCH returns official catalog
    references. SETUP / QUERY first saves and live-tests protected credentials.
  - Supply every requested field. NCEI RESOURCE is an exact station identifier
    (for example USW00013967), not a dataset name. OSM RESOURCE is restricted to
    the listed safe feature classes.
  - GDELT Event Database requires a Google Cloud project ID and short-lived OAuth
    access token for the official BigQuery public dataset. VoidCat uses named query
    parameters and refuses a query above its 5 GB billed-byte ceiling. Google Cloud
    usage charges may apply. GDELT GEO remains the no-credential news-location layer.
  - Query observations immediately appear on the map and can enter opt-in history.
    The active UNIT sees only non-expired query results, cites their observation IDs,
    and receives each provider's licensing and coverage limitations.
  - Catalog references are metadata, not live observations. Zero records means the
    bounded query found none; it never proves that no event or object exists.

Watchlists accept aircraft ICAO/callsign/tail number, vessel MMSI, satellite NORAD
ID, and geographic areas. Geofences and trigger rules can detect entry, exit,
emergency squawks, loitering, matches, and reappearance. Review rate limits and
deduplication before enabling notifications. Snapshot records a bounded live window;
Replay loads its JSONL manifest offline without consuming provider quota. Historical
storage remains opt-in and is visibly distinguished from live data.

02 — NEWS WATCH
---------------
NEWS WATCH aggregates selected RSS/Atom feeds. Toggle sources, set a keyword filter,
and refresh. Each headline links to its publisher and shows source attribution and
cache status. Refreshing uses conditional requests, response-size caps, concurrency
limits, and source-specific minimum cadences to prevent excess traffic.

03 — COMMAND
------------
COMMAND is the main chat interface. Create or select a conversation, enter a prompt,
and send it to the active UNIT. Responses stream as they are generated. STOP cancels
generation. The tool selector controls which local or external capabilities the UNIT
may call; disabled tools cannot be invoked.

Web modes:
  OFF       No web search.
  ASK FIRST VoidCat asks before an external request.
  AUTO      Approved search tools may search automatically within their limits.

Voice controls use toggle-to-talk with the bundled local speech engine. Click
START TALKING once, speak, then click STOP + TRANSCRIBE. The transcript is added
to COMMAND INPUT for review before sending. Speaking during playback interrupts it.

To choose audio hardware, open APP SETTINGS and press DETECT AUDIO DEVICES. Approve
the local microphone request, then select AUDIO INPUT and AUDIO OUTPUT. TEST SELECTED
OUTPUT verifies the speech destination. If a saved device is disconnected, choose
another device or return the selector to WINDOWS DEFAULT.

Examples:
  "Remember that my preferred report format is a one-page briefing."
  "Using only Library: Field Notes, compare these two incident reports."
  "Check Hunter-Seeker for recent earthquakes near Japan and cite observation IDs."

04 — UNIT BANK
--------------
UNIT BANK lists locally available GGUF models. Search and filters narrow the list.
Select a row to inspect file location, size, format, and capabilities. LOAD UNIT
starts the selected model. EJECT stops it and releases memory.

For safer testing, start with a UNIT under 7 GB. Do not load several large models at
once. If loading fails, use DIAGNOSTICS, confirm sufficient RAM, and try a smaller
context window under UNIT SETTINGS.

05 — OSINT DIRECTORY
--------------------
OSINT DIRECTORY is a categorized reference catalog captured from OSINT4ALL. Search by
name, description, or category. Links open externally. Directory entries are tools
and references, not endorsements; obey each site's terms and applicable law.

06 — OSINT PROVIDERS
--------------------
This page manages passive OSINT adapters. Each provider shows availability, cache,
rate limit, credential status, and a link to obtain credentials. Configure and test
a credential before use. HIBP requires explicit authorized exposure-check mode and
an exact target; discovered addresses never expand automatically.

Start an investigation with a precise seed and objective, review its budget and plan,
then choose the permitted provider steps and re-preview the policy decision before
approval. A provider can be removed from the deterministic plan, but an arbitrary
provider cannot be added. The approval ledger shows request cost, evidence limits,
and every point that still requires operator approval. Jobs show progress and support
hard cancellation. Open the saved case
to inspect the temporal ledger, entity graph, observations, claims, contradictions,
competing hypotheses, scoreable forecasts, information gaps, and MAGI role reports.

Selecting an entity synchronizes the graph, timeline, claims, contradictions, and
evidence around that subject. The evidence inspector explains why a record matters,
its freshness and directness, the claims it supports or contradicts, coverage limits,
and the retained archive hash. POSSIBLY_SAME_AS candidates also appear in a persistent
resolution queue; approve or reject them without destructively merging entities.
When two investigations used the same seed, select the older baseline and run WHAT
CHANGED to receive an evidence-cited delta instead of a full report reread.

Every factual finding should cite an [EV:evidence-id]. INSPECT ARCHIVE opens the
retained redacted provider response, original timestamps, collection parameters, and
SHA-256 integrity hash. Identity candidates remain reversible POSSIBLY_SAME_AS links;
approving one never destructively merges records. Candidates never create provider
requests, watchlists, or triggers without approval.

In COMMAND, enable only the analytical features needed for the current message. The
UNIT can search structured entities, reconstruct timelines, find graph paths, inspect
supporting or contradicting evidence, detect patterns, identify gaps, test hypotheses,
and calculate confidence. It cannot run arbitrary database queries or silently start
a proposed collection plan.

07 — PROJECTS
-------------
Projects isolate ongoing work without wiping older work. Create a project, name it,
set its chat-memory and OSINT-memory allocations, then activate it. The active project
appears in the header. Adjust budgets as the project grows; storage cleanup is scoped
and cannot touch unrelated chat memory, RAG, or Hunter history.

08 — RAG LIBRARY
----------------
RAG LIBRARY grounds answers in local files. Create or select a library, then upload a
PDF, DOCX, TXT, or Markdown file, or register a folder. VoidCat extracts text, creates
local chunks and embeddings, and indexes them. Select the libraries available to the
current chat. Citations open the local source and identify the matching passage.

Example: Register C:\Research\Case-A, select that library, then ask:
"What dates do the witness statements agree on? Cite each document."

Large folders can consume time and disk space. Register focused folders, watch the
indexing status, and avoid modifying source files while indexing is active.

09 — ARCHIVE
------------
ARCHIVE saves and reopens conversations. Select a conversation to restore it. Use
export for a portable copy and import to restore a supported export. Deleting an
archive removes that conversation but does not delete unrelated project data.

10 — PROFILES
-------------
PROFILES hold reusable UNIT behavior, system instructions, sampling preferences, and
context settings. Create a profile, choose its settings, save it, and activate it for
new chats. Keep factual reference material in RAG rather than long profile prompts.

11 — MEMORY
-----------
MEMORY contains explicit, inspectable facts approved for future retrieval. Add a
memory directly or say "remember this" in COMMAND and approve the proposed text.
Importance affects ranking. Search finds relevant memories. Edit or remove entries
at any time; "forget this" opens the same controlled removal path.

12 — WEB ACCESS
---------------
WEB ACCESS configures search behavior, allowed providers, domain restrictions, and
request limits. Retrieved pages are cleaned and treated as untrusted evidence;
webpage instructions cannot override VoidCat policy. Results show titles, URLs, and
quoted evidence. Search queries—not the whole chat—are sent to providers.

13 — DIAGNOSTICS
----------------
DIAGNOSTICS is also the RESOURCE COMMAND center. It reports CPU/GPU, process and
system memory, disk space, managed network requests, active UNIT/context use, RAG
progress, storage budgets, live-source cadence, and every managed job. Choose QUIET,
NORMAL, or MAXIMUM profile to set bounded concurrency; automatic throttling can lower
it when CPU, free memory, or disk pressure becomes unsafe. Pause/resume a module,
cancel a job or module, or use EMERGENCY STOP to cancel managed work, stop feeds and
replay, cancel RAG scans, and safely eject the VoidCat-owned UNIT. Emergency stop never
deletes chat, memory, RAG, or intelligence data. RESUME JOB DISPATCH releases the hold.

The original health report remains below the resource controls. Run it after a failed
load, blank view, or unavailable source and copy it before restarting. Opening this
screen does not load a UNIT or contact a provider.

14 — APP SETTINGS
-----------------
Configure interface effects, local voice engine/model, LAN access, privacy controls,
backups, and recovery. LAN access is off by default and requires authentication.
Voice remains local unless you deliberately configure a cloud provider.

INTERFACE EFFECTS selects OFF, LOW, MEDIUM, or HIGH animation intensity. INTERFACE
SOUND EFFECTS enables original locally synthesized cues for startup, navigation,
confirmation, warnings, failures, and UNIT initialization. TEST INTERFACE SOUND
previews the current cue. Both choices are saved and restored on future launches.

15 — UNIT SETTINGS
------------------
Adjust temperature, context window, maximum response tokens, and related generation
controls. Smaller context windows reduce memory pressure. Choose the primary local
model folder here. Add targeted scan folders, run a targeted scan, or run a bounded
full scan to discover existing GGUF files. Cancel stops an active scan. Hugging Face
and Ollama acquisition controls save models to the selected location where supported.

16 — SUPPORT_VC
---------------
SUPPORT_VC contains voluntary project support and related-project links. Copy the
Cash App handle if the desktop link cannot open. No tracking or third-party scripts
run on that page.

PRIVACY AND SAFE OPERATION
--------------------------
• Chats, memories, files, embeddings, and local voice stay on this computer.
• External activity is visibly indicated and constrained by request budgets.
• Credentials stay in the protected Electron process and are redacted from records.
• Never use OSINT features for scanning, exploitation, credential guessing, or
  unapproved exposure checks.
• Keep adequate free disk space. Do not interrupt database migrations or indexing.
• Back up project data before clearing or migrating it.
• Close VoidCat normally so active UNITs and volatile feeds are released cleanly.

TROUBLESHOOTING
---------------
Blank page: switch to another tab and return. If it persists, close and reopen the
app, then inspect DIAGNOSTICS and .voidcat/renderer-error.log.

No map records: confirm the source is enabled, read its health line, and check the next
scheduled request time. DeFlock starts with a small region index; camera records load
only after you click a region hub and replace the previously active sector. Public
YouTube Live Cameras also requires a saved YouTube Data API key and an explicit
region-hub click. A zero result
can mean valid zero coverage, a stale cache, or provider outage;
the freshness label distinguishes them.

UNIT will not load: verify the file still exists, rescan its folder, lower context,
and try a UNIT under 7 GB. Never start LM Studio separately for VoidCat operation.

RAG has no citations: confirm indexing completed, the library is selected for the
chat, and the query uses terms present in the documents.

External provider fails: verify credentials with the provider-status test, wait for
the displayed provider ceiling, and do not repeatedly force refresh.
