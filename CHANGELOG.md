# Changelog

All notable user-visible changes to VoidCat Harness are documented here. This project uses semantic versioning for published releases.

## [1.0.0] - 2026-07-28

### Added

- Local GGUF UNIT discovery, lifecycle management, streamed chat, conversation archives, profiles, and diagnostics.
- Local RAG libraries, registered-folder indexing, citations, approved memory, projects, backups, and bounded storage controls.
- Explicit web search and selected-page retrieval with source evidence and prompt-injection filtering.
- Hunter-Seeker live geospatial intelligence, source controls, caching, history, watchlists, triggers, feed health, snapshots, replay, and active-UNIT tools.
- Structured passive OSINT investigations with isolated persistence, evidence correlation, confidence explanations, controlled expansion, provider controls, and Hunter-Seeker exchange.
- Local voice controls, News Watch, OSINT4All directory, model-library management, support page, and screen-aware Evangelion-inspired interface.
- Portable Windows x64 packaging, automated regression checks, tagged release builds, checksums, and public operator documentation.

### Security

- Local-first data handling, protected credentials, bounded provider traffic, disposable-database test requirements, and passive-only OSINT policy.
