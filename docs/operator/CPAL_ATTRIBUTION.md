CPAL section 14 permits an equivalent prominent display of the defined attribution rather than requiring a specific page implementation. Modified graphical versions and Larger Works must still display the complete Exhibit B attribution whenever the application or session is launched. Section 15 treats external deployment as distribution and requires the applicable source to be made available.
